# Model Checkpoints

The released model weights are hosted externally because the checkpoint collection is too large for the GitHub repository.

**Download:** https://drive.google.com/drive/folders/1FphXghZ4p0TEZl6UjrPUbVbpQjWQ6njW?usp=sharing

After downloading the required `.pth` files, place them in this directory. For example:

```text
checkpoints/
└── best_ordinal_convnext.pth
```


For reproducibility, record the checkpoint filename and SHA-256 hash together with the experiment configuration that produced or uses it.
